# Mad Stats

A browser app for tagging and analysing Gaelic football match video: events, pitch maps, match clock, clips, reels and a PDF match report.

**Open it:** the GitHub Pages address for this repository (Settings → Pages shows it).

## Using it
- Works on phones, tablets and laptops in any modern browser. Chrome or Edge is best for exporting clips and reels.
- Install it like an app: on iPhone/iPad, tap Share → **Add to Home Screen**; on Android or a laptop, use the browser's **Install** option.
- After the first visit it works offline, which helps at grounds with poor signal.

## Your data
- Match videos are never uploaded. They stay on your device.
- Tags, match markers, clips and reels are saved in the browser on the device you tag on. Use **Save match file** / **Load match file** to back them up or move them to another device.

## Updating
Everything is in `index.html`. When it changes, bump `VERSION` in `sw.js` so installed copies show the "new version ready" message.
